## 机构与感知的分工

单电推杆通过剪式机构改变活动腰托的位置。推杆行程、腰托实际伸出量与接触信号的关系，需要结合装配测量；物料卡中的推杆规格不直接等于软件的模拟速度或百分比行程。

传感采集的引脚、JSON 协议与基线处理见[传感器硬件说明](../docs/hardware.md)。执行器驱动接入见[硬件接手说明](../HANDOFF.md)。

## 原始资料范围

原物料卡引用了 SolidWorks 零件名称及“模型图”目录。此次恢复材料包含图文物料卡，未包含相应 SLDPRT、装配体或制造图纸文件；这些文件名保留用于追溯。

原卡的“腰撑”和“S 型压力传感器”未列入编号 01–15 的物料统计，表中件数不代表整套电子系统的完整采购数量。
